# Общие блоки — спецификация

Статус: выпущено. Пакеты — `webx-ui/module-blocks` и `@webx-ui/module-blocks` (главное),
`webx-ui/module-admin` (доктор, панель на сайте). Гайд — раздел «Shared blocks»
`apps/docs/guide/layout-regions.md`.

Секция, которая стоит на многих страницах с одним и тем же содержимым — заявка над подвалом,
плашка акции, блок «Нам доверяют», — иначе делается одним из двух плохих способов. Блоком в
содержимое каждой страницы — тогда текст правят на двадцати страницах. Зоной лейаута
(`WEBX_UI_LAYOUT_REGIONS.md`) — тогда она стоит на **всех** страницах, и убрать её с «Контактов»
нельзя иначе как полем на каждой записи; клиент по вкладкам ходить не будет.

Ответ: **общий блок** — зона, которую печатает не лейаут, а тот, кто её поставил:

```blade
{{-- файловый шаблон: индекс услуг, страница статьи --}}
<x-webx-blocks::region name="request" fallback="components.request" />
```

а на странице из блоков — блок «Общий блок» с выбранной зоной, который клиент добавляет и
удаляет, как любой другой. Содержимое правится один раз, в «Регионах сайта»; где его нет — его
просто не поставили. Нужна страница со своим текстом — одна кнопка делает из общего блока обычные
на этой странице. Это и есть «одна плашка на двадцати страницах», которую компоненты
(`WEBX_UI_MODULE_BLOCKS.md` §24) не решают: у компонента нет содержимого.

Код ссылается на «§N of the shared blocks spec» — номера ниже.

## 1. Границы

**Внутри (`module-blocks`):** признак `fragment` в объявлении зоны; предложенный тип блока
`fragment` и узел схемы `wx-fragment`; отвязка («сделать отдельным»); защита от зацикливания;
предпросмотр общего блока на странице, где он есть; прокрутка превью страницы к блоку, внутри
которого зона; проверка доктора; API и MCP.

**Внутри (`module-admin`):** проверка доктора `Regions` не ищет общие блоки в лейауте; панель на
сайте — блок внутри общего правится как блок общего, с пометкой и отвязкой.

**Снаружи:** переопределение отдельных полей общего блока на странице (§7); общий блок на запись
через поле экрана (§13 спеки зон) — не нужен: общий блок ставят туда, где он нужен.

## 2. Принятые решения (не переоткрывать)

1. **Общий блок — это зона, а не новая сущность.** У зоны уже есть всё, что нужно содержимому,
   которое правят один раз: `HasBlocks`, черновик, публикация, история, откат, свой набор стилей,
   печатаемый тегом на месте, запасной вариант, предпросмотр, MCP `blocks_region_*`, панель на
   сайте. Второго хранилища нет; разница с шапкой — только в том, кто печатает тег.
2. **Признак в объявлении, не в базе.** `'fragment' => true` рядом с `title` в
   `webx-blocks.regions`. Объявление пишет тот же, кто печатает тег (решение 2 спеки зон), и
   знает, лейаут это или нет.
3. **В «Общий блок» на странице выбираются только общие зоны.** Шапка и подвал, вставленные
   посреди страницы, печатались бы дважды.
4. **Где общий блок есть — решает место, а не запись.** Поля «показывать / скрыть» на экранах
   записей нет: на странице из блоков общий блок — блок её содержимого, в файловом шаблоне —
   тег. Убрать с «Контактов» — удалить блок.
5. **Свой текст на одной странице — отвязкой, а не переопределением.** «Сделать отдельным для
   этой страницы» заменяет узел общего блока копией содержимого зоны: обычные блоки с теми же
   значениями и новыми ключами, в черновике страницы. За общим они больше не следят — панель
   говорит об этом до нажатия. Так работают detach у компонента Figma и отвязка
   синхронизированного паттерна WordPress: одна понятная операция вместо правил, какое поле чьё.
6. **Копируется опубликованное** — то, что видит посетитель: черновик общего блока может быть
   чужой незаконченной правкой. У зоны без публикации копировать нечего: кнопка недоступна.
7. **Цикл — отказ при публикации и пусто на сайте.** Общий блок, внутри которого (прямо или через
   другой общий) стоит «Общий блок» на него же, не публикуется (422, путь цикла). Рендер держит
   стек рисуемых зон: повторный вход — пустая строка и запись в лог; это страховка для дерева,
   опубликованного до проверки.
8. **Предпросмотр общего блока — на странице, где он есть, прокрученный к нему** и обведённый.
   Если на выбранной странице зоны нет — сцена с полосой «на этой странице общего блока нет».
9. **В интерфейсе — «Общий блок», в коде — `fragment`.** Клиент думает блоками; слово «зона»
   остаётся за шапкой и подвалом. «Регионы сайта» показывают общие блоки отдельной группой.

## 3. `module-blocks`, php

### 3.1. Объявление

```php
// config/webx-blocks.php
'regions' => [
    'header' => ['title' => 'trans::webx-blocks::regions.header'],
    'footer' => ['title' => 'trans::webx-blocks::regions.footer'],
    'request' => [
        'title' => 'Request',
        'description' => 'The request form above the footer.',
        'fragment' => true,
    ],
],
```

`Regions::declared()` отдаёт `fragment: bool`; `Regions::fragments()` — имена общих блоков. В
API списка зон и в `blocks_regions` — то же поле.

### 3.2. Предложенный тип `fragment` и узел `wx-fragment`

`resources/blocks/fragment.json` (механизм `BlockOffers`, §10.3 спеки тем — ставится один раз,
`webx:blocks:offered --install`): тип «Shared block» с одним полем `wx-fragment` и шаблоном
`@if ($fragment)<x-webx-blocks::region :name="$fragment" />@endif`.

Значение `wx-fragment` — имя зоны. Тип поля (`Fields\FragmentType`) проверяет, что имя объявлено
и это общий блок; иначе — ошибка поля. Пустое — блок ничего не печатает. Узел «общего блока»
везде опознаётся по типу поля `wx-fragment`, а не по slug `fragment`: тип сайт может
переименовать или сделать свой (`Fragments::placed()`).

### 3.3. Рендер

- Стек рисуемых зон в `Regions` (решение 7): вход с именем, которое уже в стеке, — пустая строка
  и `warning` в лог с путём.
- Внутри блока страницы зона печатает свой `<link rel="stylesheet">` на месте, как в лейауте.
- На странице с панелью на сайте зона внутри блока обёрнута своими `<!--wx-region:…-->`, блоки
  внутри — своими `<!--wx:…-->`, и `site-bar.js` относит их к зоне, а не к странице. В
  предпросмотре **страницы** маркеров зоны нет (`Regions::mark()` смотрит на режим панели на
  сайте) — прокрутке к блоку это не мешает, маркер блока стоит снаружи.

### 3.4. Проверка цикла

`Regions::refusals()` (та же точка, где `allow` и `max`) обходит дерево черновика: каждый узел
`wx-fragment` раскрывается в опубликованное дерево названной зоны, рекурсивно; встреча имени
публикуемой зоны — отказ `webx-blocks::regions.cycle` с путём (`request → promo → request`).
`refusals()` зовёт и сохранение черновика зоны (`RegionWriter::admissible()`), так что видимый
сразу цикл отбивается 422 при записи; сложившийся позже ловит публикация. Публикацию страницы не
проверяем — страница не зона.

### 3.5. Отвязка

`POST /api/cms/regions/{name}/copy` → `{ data: { blocks: [...] } }` — опубликованное дерево зоны с
новыми ключами на всех уровнях, значения как есть. Ничего не пишет: клиент кладёт ответ в черновик
записи вместо узла и сохраняет обычным путём — ревизия, автосейв, история работают как всегда.
Право — любое из `blocks.view` / `blocks.manage` / `blocks.regions` (его зовёт редактор страницы);
право на запись проверит её сохранение. Зона без публикации — 409
`webx-blocks::regions.copy-unpublished`; зона лейаута — 404.

### 3.6. Предпросмотр

`RegionPreviewController`: если в HTML страницы нет `<!--wx-region:{name}-->`, а зона общая,
отдаётся сцена (`stage()`) с полосой `webx-blocks::regions.not-on-page`. Для зон лейаута — как
у зон.

### 3.7. API и MCP

- Список зон: `fragment`, а у общих — `used_on`: записи, в содержимом которых (опубликованном или
  черновике, с пометкой какое) стоит узел с этим именем — одним обходом всех записей
  `webx-blocks.entities` (`Usage::fragments()`). Файловые шаблоны в `used_on` не видны — с
  пометкой. На сайте с тысячами страниц — кешировать, как `Usage::counts()`.
- `GET /blocks/fragments` — общие блоки для поля `wx-fragment` с правом каталога, без `used_on`:
  у редактора страницы может не быть `blocks.regions`, которого требует список зон.
- MCP: `blocks_regions` отдаёт `fragment` и `used_on`; ресурс модуля объясняет агенту узел
  `{ type: "fragment", values: { fragment: "<имя>" } }` и отвязку — прочитать зону
  `blocks_get_content(entity: "region")` и вставить её блоки с новыми ключами. Отдельного
  инструмента отвязки нет — это две существующие операции.

## 4. `@webx-ui/module-blocks`, панель

### 4.1. Узел `wx-fragment` в редакторе

Форма блока «Общий блок» (`FragmentField`):

- выбор общего блока (`WxSelect` по `GET /blocks/fragments`);
- статус выбранного: «Опубликован» / «Есть черновик» / «Не опубликован — на сайте запасной
  вариант» / «Пуст»;
- пояснение, что правка изменит его на всех страницах, где он стоит;
- **«Править для всех страниц»** — ссылка на редактор зоны в новой вкладке (черновик страницы не
  теряется); строится из `basePath` и пути модуля, а не роутером — во фрейме панели на сайте
  роутера нет;
- **«Сделать отдельным для этой страницы»** — подтверждение, затем `copy` (§3.5) и замена узла на
  месте с выделением первого из вставленных. Подменяет узел владелец дерева через контекст
  `blocksFragmentKey` (`BlocksField` или вкладка панели на сайте): форма блока рисуется
  рендерером экранов и до дерева сама не дотягивается.

### 4.2. Превью страницы

Выбор блока «Общий блок» прокручивает превью к нему, как к любому другому. `blockElement()`
пропускает то, что не рисуется (`link`, `style`, `script`, `template`, `meta`, `noscript`), и
берёт первый элемент с ненулевым прямоугольником: первым узлом такого блока стоит `<link>` зоны.
Просьба прокрутить ставится до замера высоты фрейма и повторяется после его роста — иначе блок
ниже первого экрана фрейма не доезжал.

### 4.3. Редактор зоны

- «Регионы сайта»: две группы — «Шапка и подвал» (зоны лейаута) и «Общие блоки».
- У общего блока над деревом — «Где стоит»: записи из `used_on` кнопками, которые переключают
  превью на эту страницу (адреса записи в панели у `used_on` нет), плюс строка «и в шаблонах
  сайта» (их не видно); общий блок внутри другого общего ведёт в редактор того.
- Превью: страница по умолчанию — первая из `used_on`, а не главная; фрейм прокручивается к
  `<!--wx-region:{name}-->` и обводит зону рамкой поверх страницы (`#wx-preview-region`), а не
  классом: зона — несколько блоков подряд, обёртка сломала бы селекторы сайта.

## 5. `module-admin`

### 5.1. Доктор

`Doctor\Checks\Regions` пропускает зоны с `fragment`: их печатает не лейаут. Проверка «общий блок
где-то стоит» живёт в `module-blocks` (`Doctor\FragmentsCheck`, регистрируется в `DoctorChecks`):
`module-admin` без блоков содержимого не знает. `ok`, если `used_on` не пуст, иначе `warn` «общий
блок никуда не поставлен» с оговоркой про файловые шаблоны.

### 5.2. Панель на сайте

- Клик по блоку внутри общего открывает его как блок зоны, с плашкой «Общий блок · … — изменится
  на всех страницах».
- Страница после разбора маркеров сообщает панели, какие зоны напечатала
  (`{ type: 'regions', names }`), и вкладка «Блоки» показывает общий блок только там, где он
  есть. Страница прошлого релиза ничего не сообщает — тогда список прежний, все объявленные зоны.
- «Сделать отдельным для этой страницы» — когда общий блок стоит в содержимом записи (а не
  напечатан шаблоном): одна правка черновика — `add` каждой копии после узла в обратном порядке,
  затем `remove`. Наборы стилей при этом странице не сообщаются: `<link>` зоны уходит вместе с
  диапазоном общего блока, а сервер, считая набор загруженным, не прислал бы стили копий.

## 6. Стартовый сайт

Первый потребитель — секция заявки `request` над подвалом: зона с `'fragment' => true`, тег в
индексе услуг, запасная вьюха `theme/views/components/request.blade.php`, на главной — блок
«Shared block» со значением `request`.

## 7. Отвергнуто и отложено

- **Поле «показывать / скрыть зону» на экранах записей** — решение 4: блок, который можно
  удалить, понятнее выключателя, который надо найти.
- **Переопределение полей на месте** («общий, но заголовок свой», pattern overrides WordPress).
  Тег зоны уже передаёт атрибуты блокам как `$region->data()`, но каждый тип должен уметь читать
  подмены, а редактор — показывать, какое поле чьё. Отложено до сайта, где отвязки окажется мало.
- **Общий блок как компонент (`kind = component`)** — у компонента нет содержимого, только код.
- **«Снова сделать общим»** — это удалить копию и поставить «Общий блок»; отдельная операция не
  нужна.
