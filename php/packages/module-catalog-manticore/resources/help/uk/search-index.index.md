# about

Окреме швидке сховище, у якому каталог сайту шукає, фільтрує й рахує. Товари потрапляють у нього самі після
збереження, тому зазвичай тут нічого робити. Відкривайте цю сторінку, коли пошук чи фільтри на сайті показують
застаріле.

# howto

## Як перевірити, що індекс у порядку

1. Подивіться блок «Сервер»: там має бути «Відповідає».
2. Подивіться «Таблиці»: у кожної мови стан «Актуальна», а числа «В індексі» й «У базі» близькі.
3. Подивіться «Чекають на запис»: число має падати само.

## Як перебудувати індекс

1. Натисніть «Перебудувати» й підтвердьте.
2. Зачекайте: сторінка показує, скільки зроблено.

Покупці можуть користуватися сайтом увесь цей час: він працює на старих даних, поки не готові нові.
Перебудувати потрібно, коли сторінка каже, що індекс застарів.
