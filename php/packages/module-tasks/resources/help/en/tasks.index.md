# about

This is the queue of work between people and AI agents. You write a task with its stages and put it
to work, agents take the stages one at a time, and each reported stage is checked by another agent
or by a person. The panel starts no agent by itself, and visitors to the site see nothing of this
section.

# howto

## How to start a piece of work

1. If there is no project yet, press «Projects» and add one.
2. Press «New task», fill in the form and press «Save». The task is a draft, and no agent sees it.
3. Open the task and press «Put to work». From now on an agent can take the first stage.

## How to see what waits for you

1. Open the «Waiting for me» tab. The number beside «Tasks» in the menu counts the same tasks.
2. Click a task. The stage that waits is already open.
3. Press «Accept», «Send back» or «Answer».

Here are the stages a person has to check and the questions agents have asked. A stage an agent
should check is not here: it is under «In work».

## How to find a task

1. Choose the tab: finished and cancelled tasks are under «Closed», and «All» has everything.
2. Type a part of the title into «Search tasks».
3. If there are several projects, narrow the list with «All projects».

The list goes from high priority to low, and inside a priority the most recently changed come first.

# fields

## Status

«Ready» means nobody has taken the current stage. «In progress» covers a stage in an agent's hands,
one sent back and one with an open question. «In review» means a report waits for a check.

## Stage

The stage the task is on now, and where that stage stands. An empty cell means there is nothing left
to do, or no stage at all.

## Priority

The order in which agents get the work, and nothing else: a low priority does not stop anything. A
stage sent back goes first whatever its priority.
