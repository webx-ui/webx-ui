# fields

## configurator-key

Для товара, который продаётся под размер: покупатель попадёт со страницы товара в конфигуратор. Пока
конфигуратор не опубликован и его страницы нет на сайте, кнопки покупатель не увидит.

## configurator-preset

Экономит покупателю несколько шагов: конфигуратор откроется уже с этим товаром. Там всё можно поменять.
