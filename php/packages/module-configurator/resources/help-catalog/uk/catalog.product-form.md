# fields

## configurator-key

Для товару, який продається під розмір: покупець потрапить зі сторінки товару в конфігуратор. Поки
конфігуратор не опубліковано і його сторінки немає на сайті, кнопки покупець не побачить.

## configurator-preset

Економить покупцеві кілька кроків: конфігуратор відкриється вже з цим товаром. Там усе можна змінити.
