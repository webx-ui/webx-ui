# about

Конфігуратор дає відвідувачеві зібрати товар під розмір: вибрати варіанти, ввести розміри й одразу побачити
ціну. Тут видно всі конфігуратори, які з них на сайті й яка форма приймає їхні заявки.

# howto

## Як зробити конфігуратор

1. Натисніть «Новий конфігуратор», заповніть назву й ключ і натисніть «Створити».
2. У редакторі, що відкриється, додайте кроки.
3. Натисніть «Опублікувати».
4. Додайте його блок на сторінку сайту.

## Як повернути видалений конфігуратор

1. Відкрийте «Кошик» над списком.
2. Натисніть «Відновити».

Він повернеться таким, яким був, із тим самим ключем.
