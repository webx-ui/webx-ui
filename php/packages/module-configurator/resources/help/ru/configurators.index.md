# about

Конфигуратор даёт посетителю собрать товар под размер: выбрать варианты, ввести размеры и сразу увидеть
цену. Здесь видны все конфигураторы, какие из них на сайте и какая форма принимает их заявки.

# howto

## Как сделать конфигуратор

1. Нажмите «Новый конфигуратор», заполните название и ключ и нажмите «Создать».
2. В открывшемся редакторе добавьте шаги.
3. Нажмите «Опубликовать».
4. Добавьте его блок на страницу сайта.

## Как вернуть удалённый конфигуратор

1. Откройте «Корзину» над списком.
2. Нажмите «Восстановить».

Он вернётся таким, как был, с тем же ключом.
