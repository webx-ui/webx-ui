# about

A feed is a file with your products for a marketplace or an advertising platform. The site builds it
by itself and keeps it at a permanent address, which you give to the platform. Here you see each feed,
how many products it holds and when it was last built.

# howto

## How to make a feed for a marketplace

1. Press «New feed», choose a preset and press «Continue».
2. Fill in the name and choose which products go in on the «Selection» tab.
3. Press «Create», then copy the address on the «General» tab.
4. Paste the address into the marketplace's account.

## How to find out why a feed did not build

1. Open the feed and go to its «Journal» tab.
2. Open the row of the build: it says what went wrong and which products stayed out.

If a build fails, the last good file goes on being served.
