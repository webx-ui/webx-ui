# about

These are the house rules for AI agents that write the content of the site: how it speaks, what it
never says, and what else is worth knowing. They are kept on the page «Connect an agent», in the
card «Rules for agents», with a «Save» of their own, and not on the «Settings» page. Visitors never
see the rules, only the texts agents write by them.

# howto

## How to give agents the rules of the site

1. Open the page «Connect an agent» and find the card «Rules for agents».
2. In «Tone of voice», say in a few lines how the site speaks.
3. In «Don'ts», write what the site never says, one thing per line.
4. In «Notes for the agent», add what an agent cannot guess.
5. Press «Save» in the card.

Agents read the rules before they write, so texts already on the site stay as they are. Without the
right to change settings the card can be read, and it has no «Save».

# fields

## tone

Visitors never read this field, only the texts written by it. Describe the voice as you would to a
new copywriter. One text is enough for all languages: the field is not per language, and agents
follow it in each of them.

## donts

Each line reaches the agent as a separate rule, and empty lines are dropped. Nothing checks the
finished text against this list, so read what an agent writes where a slip would be costly.

## notes

Good for what an agent cannot guess: the spelling of your name, the words you prefer. Every
connected agent reads this field, so keep passwords and private details out of it. Visitors do not
see it.
