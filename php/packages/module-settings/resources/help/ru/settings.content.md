# about

Это внутренние правила для ИИ-агентов, которые пишут тексты сайта: как он говорит, чего
никогда не говорит и что ещё важно знать. Лежат они не на странице «Настройки», а на странице
«Подключение агента», в карточке «Правила для агентов», и сохраняются своей кнопкой. Посетитель
самих правил не видит, только тексты, написанные по ним.

# howto

## Как дать агентам правила сайта

1. Откройте страницу «Подключение агента» и найдите карточку «Правила для агентов».
2. В поле «Тон» скажите в нескольких строках, как говорит сайт.
3. В поле «Чего нельзя» напишите, чего сайт никогда не говорит, по одному на строку.
4. В поле «Заметки для агента» добавьте то, о чём агент не догадается сам.
5. Нажмите «Сохранить» в карточке.

Агенты читают правила перед тем, как писать, так что тексты, уже лежащие на сайте, не меняются. Без
права менять настройки карточку можно только читать, и кнопки «Сохранить» в ней нет.

# fields

## tone

Посетитель это поле не читает, только тексты, написанные по нему. Опишите голос сайта так, как
объяснили бы новому копирайтеру. Одного текста хватит на все языки: поле не делится по языкам, и
агенты следуют ему на каждом из них.

## donts

Каждая строка доходит до агента отдельным правилом, пустые строки отбрасываются. Готовый текст с
этим списком никто не сверяет, так что читайте написанное агентом там, где ошибка дорого обойдётся.

## notes

Подходит для того, о чём агент сам не догадается: как пишется ваше название, какие слова вы
предпочитаете. Это поле читает каждый подключённый агент, поэтому паролям и личным данным тут не
место. Посетитель его не видит.
