# about

Форма одного человека из команды. Черновика здесь нет: всё, что вы сохранили у опубликованного
человека, сразу на сайте. Опубликованный человек виден на всех языках сайта, что бы ни было
переведено.

# howto

## Как добавить соцсети

1. В поле «Соцсети» нажмите «Добавить ссылку».
2. Выберите «Сеть» и заполните «Адрес».
3. Перетащите строки в нужном порядке.
4. Нажмите «Сохранить».

## Как перевести человека

1. Переключите форму на нужный язык.
2. Заполните «Текст», а «Должность» — если на этом языке она звучит иначе.
3. Нажмите «Сохранить».

# fields

## photo

Фото стоит на карточке в круге, поэтому держите лицо в центре кадра. Берите только снимок, который
человек разрешил показывать.

## name

Без него на языке по умолчанию форма не сохранится. Посетитель видит имя на карточке, а если нет
фото, из него собираются инициалы.

## job-title

Переводите только там, где она звучит иначе. Пустая должность следа на карточке не оставляет.

## text

Несколько строк о человеке на карточке, переносы строк сохраняются. У блока есть настройка, которая
прячет текст сразу у всех.

## socials

Ссылки стоят на карточке значками и открываются в новой вкладке. Одному человеку можно добавить
не больше 20 ссылок.

## social-network

Список задаёт сам сайт; нужную сеть добавит разработчик. У семи привычных сетей есть значок, а любая
другая печатается названием.

## social-url

Полный адрес профиля, начинается с http:// или https://: другой форма не примет. Строка только с
сетью или только с адресом не сохранится. Посетитель видит значок, а не адрес.

## services

Поле есть на сайтах с разделом «Услуги». На карточке человека появятся ссылки на эти услуги.

## published

Выключите, чтобы убрать человека сразу со всех страниц: в панели он останется с пометкой «Не
опубликован». Черновика нет, поэтому правки опубликованного человека заранее нигде не посмотреть.
