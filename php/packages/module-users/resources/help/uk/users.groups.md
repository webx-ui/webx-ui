# about

Група збирає клієнтів, яких сайт має розрізняти: в інтернет-магазину запчастин це можуть бути
«Автосервіси» й «Приватні покупці». Сама собою група нічого не змінює: вона працює лише там, де щось
на сайті налаштовано на неї дивитися, тому перш ніж на неї розраховувати, запитайте того, хто
налаштовував сайт. Клієнти своїх груп не бачать.

# howto

## Як створити групу й додати до неї клієнтів

1. Натисніть «Нова група», заповніть «Назва» й «Код» і натисніть «Зберегти».
2. Відкрийте клієнта в розділі «Клієнти».
3. Відмітьте групу в полі «Групи клієнта».
4. Збережіть картку.

Клієнти додаються по одному: дії одразу для багатьох у списку клієнтів немає.

## Як подивитися, хто в групі

1. Знайдіть групу: колонка «Клієнтів» каже, скільки їх.
2. Відкрийте меню «···» в її рядку.
3. Виберіть «Клієнти». Відкриється список із фільтром за цією групою.

## Як видалити групу

1. Відкрийте меню «···» в рядку й виберіть «Видалити».
2. Перевірте, скільки клієнтів названо в діалозі.
3. Підтвердьте.

Клієнти залишаться й просто вийдуть із групи. Повернути це не можна: група, створена заново з тим самим
кодом, буде порожньою, і клієнтів доведеться відмічати знову.

# fields

## Назва

Її показує лише панель: у цьому списку, у картці клієнта й у фільтрі. Пишеться один раз, однією мовою,
і групи в списку йдуть за нею.

## Код

Усе, що на сайті дивиться на групу, шукає її за цим кодом. Якщо код змінити, там групу перестануть
упізнавати, доки код не змінять і там, хоча клієнти в групі залишаться. Двох груп з одним кодом бути не
може.
