# about

A group gathers customers the site should tell apart: for an auto parts shop, «Workshops» and
«Private buyers». A group changes nothing by itself: it matters only where something on the site has
been set up to read it, so ask whoever set up the site before relying on one. Customers never see
their groups.

# howto

## How to make a group and put customers in it

1. Press «New group», fill in «Name» and «Code» and press «Save».
2. Open the customer in the section «Customers».
3. Tick the group under «Customer groups».
4. Save the card.

Customers are added one at a time: the list of customers has no action for many at once.

## How to see who is in a group

1. Find the group: the column «Customers» says how many there are.
2. Open the «···» menu of its row.
3. Choose «Customers». The list opens with the filter by this group.

## How to delete a group

1. Open the «···» menu of the row and choose «Delete».
2. Check how many customers the dialog names.
3. Confirm.

The customers stay and only leave the group. There is no way back: a group made again under the same
code starts empty, and its customers have to be ticked anew.

# fields

## Name

Only the panel shows it: in this list, in the card of a customer and in the filter. It is written
once, in one language, and the groups are listed by it.

## Code

Whatever on the site reads a group looks for it by this code. After a change the group stops being
recognised there until the code is changed there too, though its customers stay in it. Two groups
cannot share a code.
