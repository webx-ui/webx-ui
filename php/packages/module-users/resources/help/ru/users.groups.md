# about

Группа собирает клиентов, которых сайт должен различать: у интернет-магазина запчастей это могут быть
«Автосервисы» и «Частные покупатели». Сама по себе группа ничего не меняет: она работает только там,
где что-то на сайте настроено на неё смотреть, поэтому прежде чем на неё рассчитывать, спросите того,
кто настраивал сайт. Клиенты свои группы не видят.

# howto

## Как создать группу и добавить в неё клиентов

1. Нажмите «Новая группа», заполните «Название» и «Код» и нажмите «Сохранить».
2. Откройте клиента в разделе «Клиенты».
3. Отметьте группу в поле «Группы клиента».
4. Сохраните карточку.

Клиенты добавляются по одному: действия сразу для многих в списке клиентов нет.

## Как посмотреть, кто в группе

1. Найдите группу: колонка «Клиентов» говорит, сколько их.
2. Откройте меню «···» в её строке.
3. Выберите «Клиенты». Откроется список с фильтром по этой группе.

## Как удалить группу

1. Откройте меню «···» в строке и выберите «Удалить».
2. Проверьте, сколько клиентов названо в диалоге.
3. Подтвердите.

Клиенты останутся и просто выйдут из группы. Вернуть это нельзя: группа, созданная заново с тем же
кодом, будет пустой, и клиентов придётся отмечать снова.

# fields

## Название

Его показывает только панель: в этом списке, в карточке клиента и в фильтре. Пишется один раз, на
одном языке, и группы в списке идут по нему.

## Код

Всё, что на сайте смотрит на группу, ищет её по этому коду. Если код поменять, там группу перестанут
узнавать, пока код не поменяют и там, хотя клиенты в группе останутся. Двух групп с одним кодом быть
не может.
