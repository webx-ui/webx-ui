# about

Здесь все, у кого есть аккаунт на сайте: кто зарегистрировался сам, пришёл через соцсеть или был
добавлен вручную. Клиенты живут отдельно от администраторов, в панель клиент не попадёт никогда.
Список нужен, чтобы найти человека, а всё, что касается клиента, меняется в его карточке.

# howto

## Как найти клиента

1. Введите в поиск часть имени, e-mail или телефона.
2. Чтобы сузить список, откройте «Фильтры» и выберите группу, состояние адреса, способ входа,
   блокировку или даты регистрации.
3. Нажмите на строку, чтобы открыть карточку.

Телефон находится по цифрам, как бы он ни был записан. Чтобы увидеть, кто заходит на сайт, выберите
«Недавно входили» в поле «Порядок»: клиенты, которые ни разу не входили, окажутся в конце.

## Как напомнить клиентам, которые не подтвердили адрес

1. Откройте «Фильтры» и выберите «Не подтверждён» в поле «Адрес».
2. Откройте клиента из списка.
3. В меню «···» вверху карточки выберите «Отправить письмо для подтверждения».

У таких клиентов рядом с e-mail стоит значок предупреждения. Входить на сайт они всё равно могут, а
сайт напоминает им об адресе на каждой странице.

## Как найти клиентов одной соцсети

1. Откройте «Фильтры» и выберите соцсеть в поле «Входит через».
2. Посмотрите на колонку «Вход». Зачёркнутая соцсеть отключена, через неё никто не войдёт.
3. Если больше у клиента там ничего нет, откройте карточку и нажмите «Отправить приглашение ещё
   раз»: клиент задаст пароль.

Кнопки в карточке есть у тех, кому разрешено менять клиентов.
