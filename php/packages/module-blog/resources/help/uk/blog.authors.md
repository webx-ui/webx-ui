# about

Профіль робить з адміністратора, який пише, людину, яку бачать відвідувачі: ім'я, посаду, фото й,
якщо потрібно, сторінку з усіма його статтями. Без профілю статті підписані ім'ям облікового запису.
На один обліковий запис — один профіль.

# howto

## Як додати автора

1. Натисніть «Новий автор».
2. У полі «Обліковий запис» виберіть, чиї це статті. Вибір робиться один раз, потім його не змінити.
3. Заповніть «Ім’я на сайті» основною мовою.
4. Натисніть «Зберегти». Підпис під статтями цього автора одразу зміниться.

## Як зробити авторові сторінку

1. Виберіть автора у списку.
2. Увімкніть «Сторінка на сайті» й заповніть «Адресу».
3. Натисніть «Зберегти». У списку замість позначки «Без сторінки» з'явиться «Сторінка на сайті».
4. Натисніть «Відкрити сторінку» й перевірте її.

## Як прибрати профіль

1. Виберіть автора у списку.
2. Натисніть «Видалити» й підтвердьте.

Статті залишаться на сайті, під ними буде ім'я облікового запису. Сторінка автора перестане
відповідати.
