# about

Профиль делает из администратора, который пишет, человека, которого видят посетители: имя,
должность, фото и, если нужно, страницу со всеми его статьями. Без профиля статьи подписаны именем
учётной записи. На одну учётную запись — один профиль.

# howto

## Как добавить автора

1. Нажмите «Новый автор».
2. В поле «Учётная запись» выберите, чьи это статьи. Выбор делается один раз, потом его не изменить.
3. Заполните «Имя на сайте» на основном языке.
4. Нажмите «Сохранить». Подпись под статьями этого автора сразу сменится.

## Как сделать автору страницу

1. Выберите автора в списке.
2. Включите «Страница на сайте» и заполните «Адрес».
3. Нажмите «Сохранить». В списке вместо пометки «Без страницы» появится «Страница на сайте».
4. Нажмите «Открыть страницу» и проверьте её.

## Как убрать профиль

1. Выберите автора в списке.
2. Нажмите «Удалить» и подтвердите.

Статьи останутся на сайте, под ними будет имя учётной записи. Страница автора перестанет отвечать.
