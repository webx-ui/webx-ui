# about

Here live the pieces of code outside services ask to put on the site: counters, online chats, tags
that prove you own the site. The codes are grouped by the place on the page they are printed in, and
the open code stands beside the list. A code runs in the browser of every visitor, so give this
section only to people you trust.

# howto

## How to add a code from a service

1. Press «+» beside the place the service names.
2. Fill in «Name» and paste what the service gave you into «Code».
3. If the code counts or follows visitors, choose a category in «Cookie consent».
4. Switch on «Enabled» and press «Save».
5. Open the site and check on the side of the service that the code is seen.

## How to take a code off the site for a while

1. Find the code in the list.
2. Switch off the switch in its row. This happens at once, without «Save».
3. Switch it on again when the code is needed. Everything in it is kept.

Meanwhile the row carries the «Off» mark, and visitors do not get the code.

## How to change the order of codes or move one to another place

1. Take the code by its grip.
2. Drag it up or down inside its place, or into another place.
3. Let go. The new order saves by itself.

Inside a place the codes are printed from top to bottom. A code dragged into another place moves
there at once, on the live site too.

## How to get a deleted code back

1. Open the «Bin» tab.
2. In the «···» menu of the code, press «Restore».
3. Open the «Codes» tab and look at its switch.

The code comes back as it was: one that was enabled is on the site again at once. «Delete for good»
in the same menu removes it with its history, and that cannot be undone.

## What to do about a mark beside a place

1. «Not printed on any page yet»: open a page of the site, then reload this list.
2. If the mark stays, tell whoever looks after the site: the design of the site has lost this place,
   and its codes reach nobody.
3. «Not declared»: this place is gone from the site, and its codes are printed nowhere.
4. Open each code there and choose another «Place», or switch it off to keep it.

## Why a code does not work on a copy of the site

1. Look at the top of the list: a warning there says this copy prints only some of the codes.
2. A grey «Not printed on this copy» beside a code means the real site prints it and this one does
   not.
3. To try the code here, open it, switch on «On dev and stage too» and press «Save».
