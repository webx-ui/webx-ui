# about

Один код: что это, куда он встаёт на странице, на каких страницах и языках выводится. Черновика
здесь нет: «Сохранить» у включённого кода сразу ставит его на сайт, вместе с ошибками, если они
есть. Если в коде есть `<html>`, `<head>` или `<body>`, он всё равно сохранится, а предупреждение
над формой скажет, что убрать.

# howto

## Как заставить счётчик ждать согласия

1. Вставьте код счётчика в «Код».
2. В «Согласие на cookie» выберите «Аналитика» для счётчика или «Маркетинг» для рекламы.
3. Нажмите «Сохранить».
4. Откройте сайт в приватном окне: счётчик запустится, только когда вы согласитесь в баннере.

«Аналитика» здесь — то, что в баннере называется «Статистика».

## Как поставить код на часть сайта

1. В «Только на» добавьте пути, для которых нужен код: например, `/blog` и `/blog/*`.
2. В «Кроме» добавьте пути, которые надо из них исключить.
3. В «Языки» отметьте языки, если код нужен не на всех.
4. Нажмите «Сохранить» и откройте одну страницу из списка и одну не из него.

## Как вернуть прежнюю версию кода

1. Найдите нужное сохранение в блоке «История» под формой.
2. Скопируйте оттуда старый код: прежнее значение зачёркнуто.
3. Вставьте его в «Код» и нажмите «Сохранить».

Кнопки, которая сделала бы это за вас, нет, а весь код до каждого сохранения панель хранит.

# fields

## name

По этому названию вы будете искать код в списке и в блоке «История», поэтому назовите сервис и его
работу: «Счётчик посещений», «Онлайн-чат». Два кода одного сервиса с похожими названиями легко
перепутать.

## place

Следуйте инструкции сервиса: обычно он сам говорит, куда ставить код. «Head, как можно выше»
запускается раньше всех, и тяжёлый скрипт там может замедлить открытие страниц. В неподходящем месте
код может просто не заработать, и сервис его не увидит.

## code

Всё, что сюда вставлено, работает у каждого посетителя и у каждого администратора, открывшего сайт,
поэтому берите код только у сервиса, которому доверяете. Ошибка может испортить страницы, так что
после сохранения откройте сайт. Длиннее 64 КБ код быть не может.

## enabled

Выключенный код хранится, но ни один посетитель его не получает. Новый код сначала выключен.
Переключатель в списке срабатывает сразу, а этот ждёт кнопки «Сохранить».

## consent

«Необходимые» запускаются у всех сразу, поэтому оставьте их для того, без чего сайт не обойдётся:
счётчику место в «Аналитика», рекламе в «Маркетинг». Баннер сам предложит категорию, как только она
понадобится коду. Если баннер выключен, код работает у всех.

## on_stage

Для счётчиков и рекламы оставьте выключенным, иначе копия сайта добавит визиты, которых не было.
Включайте, чтобы сначала попробовать код на копии. На настоящем сайте это ничего не меняет.

## only_paths

На других страницах посетители кода не получат, а «Кроме» важнее этого списка. `/blog/*` — страницы
внутри блога, но не сам `/blog`, поэтому добавляйте оба. Пишите путь без косой черты в конце, иначе
он ни с чем не совпадёт.

## except_paths

Важнее, если страница есть в обоих списках. Пишется так же, как «Только на»: от начала пути, со `*`,
без косой черты в конце. Один путь покрывает страницу сразу на всех языках.

## locales

Удобно для онлайн-чата, который отвечает на одном языке. На странице на другом языке посетитель кода
не получит, даже если страница подходит под «Только на».
