# about

Способы — это то, из чего покупатель выбирает при оформлении заказа: забрать заказ в вашей точке,
получить его с вашим курьером или, если установлена служба доставки, отправить этой службой. Сначала
покупатель выбирает город и видит только те способы, которые там работают. Порядок этого списка — это
порядок в оформлении заказа.

# howto

## Как предложить самовывоз из своих точек

1. В разделе «Свои точки» добавьте точки, где покупатели будут забирать заказы.
2. Вернитесь в «Способы», нажмите «Добавить способ», выберите «Самовывоз из точек магазина» и нажмите
   «Добавить».
3. Заполните «Название» и «Цену», выберите «Вид точек».
4. Нажмите «Сохранить».

Способ появится в городах, где есть активная точка этого вида. Магазин и пункт выдачи — это два
способа, у каждого своё название и своя цена.

## Как предложить доставку своим курьером

1. Нажмите «Добавить способ», выберите «Курьер магазина» и нажмите «Добавить».
2. В поле «Населённые пункты» добавьте все города, куда ездит курьер.
3. Укажите «Цену»: она одна на все эти города.
4. Нажмите «Сохранить».

## Как на время перестать предлагать способ

1. Нажмите на способ в списке.
2. Выключите «Включён».
3. Нажмите «Сохранить».

Способ останется в списке с пометкой «Выключен» и со всеми настройками. Заказы, где он уже выбран, не
изменятся.

## Как понять, почему способа нет в каком-то городе

1. Откройте способ и проверьте, что «Включён» включено, а поле «Страны» не исключает страну этого
   города.
2. Для самовывоза проверьте в разделе «Свои точки», что в городе есть активная точка этого вида.
3. Для курьера магазина проверьте, что город есть в поле «Населённые пункты».
4. Для способа службы доставки, если такой есть, проверьте в разделе «Службы доставки», что служба
   включена.

Способ с пометкой «Его тип не установлен» не предлагается нигде: то, на чём он работал, с сайта
удалено.
