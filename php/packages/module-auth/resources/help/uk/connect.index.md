# about

Тут ви підключаєте AI-агента, наприклад Claude, ChatGPT або Cursor, щоб він працював у цій панелі
від вашого імені. Він може лише те, що можете ви, усе зроблене ним записується на ваше ім'я, а те,
що він змінить на сайті, побачать відвідувачі. Відкрити цю сторінку може будь-який адміністратор:
окремого права вона не потребує.

# howto

## Як підключити агента

1. Натисніть «Скопіювати адресу». Адреса не секрет: сама по собі вона нічого не відкриває.
2. У блоці «Як додати» відкрийте вкладку своєї програми й виконайте кроки. Для Cursor і VS Code те
   саме зроблять кнопки в блоці «В один клік».
3. Програма відкриє цей сайт у браузері. Увійдіть зі звичайним паролем: програма його не побачить.
4. Прочитайте, хто просить доступ і куди йдуть відповіді. Для початку ввімкніть «Лише читання».
5. Натисніть «Дозволити». Агент з'явиться в блоці «Ваші підключення».

Якщо панель каже, що програму не підключити, зверніться до того, хто веде сайт: пускають лише
програми з адрес із дозволеного списку. Якщо ви суперадміністратор, ваш агент теж зможе все, тому
підключайте його з акаунта з роллю.

## Як відключити свого агента

1. Знайдіть його в блоці «Ваші підключення».
2. Натисніть «Відключити» й підтвердьте.

Доступ зникне одразу, а змінене ним залишиться зміненим. Підключити його знову можна тими самими
кількома кліками. Агент, яким ви не користувалися місяць, сам попросить підключити його заново.

## Як дозволити агентові писати після «Лише читання»

1. Натисніть «Відключити» поруч із ним і підтвердьте.
2. Підключіть його заново зі своєї програми.
3. Цього разу не вмикайте «Лише читання» й натисніть «Дозволити».

## Як дати програмі свій ключ

1. У блоці «Ваші ключі» натисніть «Випустити ключ».
2. Заповніть форму й натисніть «Випустити».
3. Одразу скопіюйте ключ: він показується лише цього разу.

Ключ потрібен програмі, яка працює, коли біля екрана нікого немає. Якщо перед агентом сидите ви,
підключіть його, а ключа не випускайте.

# fields

## Адреса цієї панелі для агентів

Одна для всіх, її можна зачитати на дзвінку або вставити в чат: агента все одно має впустити людина
з акаунтом.

## Ваші підключення

Лише ваші агенти. Сірий рядок — відключений агент, він залишається для історії.

## Ваші ключі

Лише ваші ключі. Ключ не може більше, ніж ви, і зупиняється, якщо ваш акаунт вимкнуть або видалять.
