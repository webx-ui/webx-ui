# about

Здесь вы подключаете AI-агента, например Claude, ChatGPT или Cursor, чтобы он работал в этой панели
от вашего имени. Он может только то, что можете вы, всё сделанное им записывается на ваше имя, а то,
что он изменит на сайте, увидят посетители. Открыть эту страницу может любой администратор:
отдельного права она не требует.

# howto

## Как подключить агента

1. Нажмите «Скопировать адрес». Адрес не секрет: сам по себе он ничего не открывает.
2. В блоке «Как добавить» откройте вкладку своей программы и выполните шаги. Для Cursor и VS Code то
   же самое сделают кнопки в блоке «В один клик».
3. Программа откроет этот сайт в браузере. Войдите с обычным паролем: программа его не увидит.
4. Прочитайте, кто просит доступ и куда уходят ответы. Для начала включите «Только чтение».
5. Нажмите «Разрешить». Агент появится в блоке «Ваши подключения».

Если панель говорит, что программу не подключить, обратитесь к тому, кто ведёт сайт: пускают только
программы с адресов из разрешённого списка. Если вы суперадминистратор, ваш агент тоже сможет всё,
поэтому подключайте его из аккаунта с ролью.

## Как отключить своего агента

1. Найдите его в блоке «Ваши подключения».
2. Нажмите «Отключить» и подтвердите.

Доступ пропадёт сразу, а изменённое им останется изменённым. Подключить его снова можно теми же
несколькими кликами. Агент, которым вы не пользовались месяц, сам попросит подключить его заново.

## Как разрешить агенту писать после «Только чтение»

1. Нажмите «Отключить» рядом с ним и подтвердите.
2. Подключите его заново из своей программы.
3. На этот раз не включайте «Только чтение» и нажмите «Разрешить».

## Как дать программе свой ключ

1. В блоке «Ваши ключи» нажмите «Выпустить ключ».
2. Заполните форму и нажмите «Выпустить».
3. Сразу скопируйте ключ: он показывается только в этот раз.

Ключ нужен программе, которая работает, когда у экрана никого нет. Если перед агентом сидите вы,
подключите его, а ключ не выпускайте.

# fields

## Адрес этой панели для агентов

Один для всех, его можно зачитать на созвоне или вставить в чат: агента всё равно должен впустить
человек с аккаунтом.

## Ваши подключения

Только ваши агенты. Серая строка — отключённый агент, она остаётся для истории.

## Ваши ключи

Только ваши ключи. Ключ не может больше, чем вы, и останавливается, если ваш аккаунт выключат или
удалят.
