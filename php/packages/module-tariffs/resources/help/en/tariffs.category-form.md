# about

The name of a group and whether it is shown. A save reaches the site at once. Which tariffs are in
the group is chosen in each tariff, in its «Groups» field.

# fields

## title

Here it names the group in the filter of the list of tariffs and in the tariff's form. The standard
«Tariffs» block does not print it: visitors read it only where a site's template shows groups, as
tabs for example.

## is-visible

The standard «Tariffs» block does not look at this switch, so visitors of a page with it notice
nothing. It only matters where a site's template shows the groups as tabs.
