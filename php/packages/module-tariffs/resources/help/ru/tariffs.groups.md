# about

Группа собирает тарифы: «Для частных», «Для бизнеса». Адреса и своей страницы у неё нет: по группе
блок «Тарифы» выбирает, что показать. Один тариф может быть в нескольких группах.

# howto

## Как добавить группу

1. Нажмите «Новая группа».
2. Заполните «Название» и нажмите «Создать». Группа откроется.
3. Проверьте «Показывать на сайте» и нажмите «Сохранить».
4. Откройте тариф и добавьте его в группу в поле «Группы».

## Как поменять порядок групп

1. Перетащите группу на новое место.
2. Порядок сохранится сам.

Это важно там, где шаблон сайта показывает группы одну за другой, например вкладками.

## Как посмотреть тарифы группы

1. Нажмите «···» в конце строки.
2. Нажмите «Показать её тарифы». Откроется список тарифов, суженный до этой группы.

Там же можно перетащить порядок тарифов внутри группы.

## Как удалить группу

1. Откройте каждый её тариф и уберите группу из поля «Группы». В строке видно, сколько их осталось.
2. Нажмите «···» в конце строки, затем «Удалить».
3. Подтвердите.

Группу с тарифами удалить нельзя. Кнопки «Восстановить» в этом списке нет, поэтому удалённую группу
придётся создавать заново.
