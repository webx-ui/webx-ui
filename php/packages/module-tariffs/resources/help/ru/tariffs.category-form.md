# about

Название группы и то, показывается ли она. Сохранённое сразу попадает на сайт. Какие тарифы входят в
группу, выбирается в самих тарифах, в поле «Группы».

# fields

## title

Здесь это имя группы в фильтре списка тарифов и в форме тарифа. Стандартный блок «Тарифы» его не
печатает: посетитель прочитает его только там, где шаблон сайта показывает группы, например
вкладками.

## is-visible

Стандартный блок «Тарифы» на этот переключатель не смотрит, поэтому посетитель страницы с таким
блоком ничего не заметит. Он важен только там, где шаблон сайта показывает группы вкладками.
