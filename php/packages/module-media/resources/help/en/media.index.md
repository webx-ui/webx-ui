# about

The library of the site: every picture, video and document that pages and forms use, in folders. A
file is stored once and can stand in many places, so a change to it shows everywhere it is used.
Folders are for your own order: visitors do not see them.

# howto

## How to upload files

1. Choose a folder on the left.
2. Press «Upload» and pick the files, or drag them straight onto the list.
3. Wait for the progress to finish. If the connection drops, the upload carries on when it returns.

JPEG, PNG and WebP pictures are made lighter on the way in, so the stored file can be smaller than
yours. If the same file is already in the folder, the library says so and keeps one copy.

## How to put files in order

1. Press «New folder» under the folder tree and give it a name.
2. Select the files: draw a frame around them, or tap each one.
3. Drag them onto the folder, or press «Move» over the list and choose it.

Moving and renaming change nothing on the site: the address of a file does not depend on them. If
you moved the wrong files, press «Undo» in the message.

## How to crop or turn a picture

1. Open the menu on the card of the picture and press «Edit».
2. Crop, turn or flip it and set the size.
3. Press «Save».

The picture changes in every place it stands, and the panel has no button to undo this. If only one
page needs another crop, upload a separate file for it.

## How to delete a file safely

1. Select the files and press «Delete» over the list.
2. If the dialog lists «Still used on the site», check those places.
3. Press «Delete only the unused», or «Delete anyway» if you accept the loss.

There is no bin here: the file is gone, and where it was used the site shows a broken picture or a
dead link. Deleting a folder takes everything in it.

## How to make old pictures lighter

1. Select the pictures, or open their folder: the button takes the selection, or else the whole
   folder.
2. Press «Optimize» and check how many pictures are waiting.
3. Press «Optimize» in the dialog and wait. «Stop» ends it after the current few pictures.

Addresses stay as they are, and the previous versions are not kept. With «Convert to WebP» on, JPEG
and PNG pictures get a new address: the site's pages are updated by themselves, and the old address
leads to the new one.

# fields

## Alt text

The description of a picture for screen readers and search engines, in each language of the site. It
is shown wherever the picture stands without an alt of its own, so one description serves many
pages. Leave it empty for a purely decorative picture.
