# howto

## How to fill in the specifications of a product

1. On «Main», choose the «Main category»: it decides which properties the product has.
2. Open the «Specifications» tab.
3. Fill in the values and press «Save».

If a property you need is not there, add it to the category on its «Properties» tab.

# fields

## properties-values

These values go into the specifications on the product page and the catalogue filter, wherever the
property is set up for that. A product without a value does not appear when buyers filter by it.
Values left over from an earlier category are kept but shown nowhere, and the tab offers to delete
them.
