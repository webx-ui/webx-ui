# howto

## Как заполнить характеристики товара

1. На вкладке «Основное» выберите «Основную категорию»: от неё зависит, какие свойства есть у товара.
2. Откройте вкладку «Характеристики».
3. Заполните значения и нажмите «Сохранить».

Если нужного свойства нет, добавьте его категории на её вкладке «Свойства».

# fields

## properties-values

Эти значения попадают в характеристики на странице товара и в фильтр каталога, где свойство для этого
настроено. Товар без значения не появится, когда покупатель отбирает по нему. Значения, оставшиеся от
прежней категории, хранятся, но нигде не видны, и вкладка предложит их удалить.
