# about

Свойство — это одна черта, которой описывается товар: цвет, вес, Wi-Fi. Здесь вы решаете, какое у него
значение и где покупатель его встретит: в фильтре, на плитке, в характеристиках. Само значение
заполняется у каждого товара.

# howto

## Как задать свойству список значений

1. На вкладке «Основное» выберите тип «Справочник» и нажмите «Сохранить».
2. Откройте вкладку «Значения».
3. Введите значение и нажмите Enter, затем следующее.

## Как слить два значения с одним смыслом

1. На вкладке «Значения» найдите лишнее значение и нажмите «Слить с…».
2. Выберите значение, которое останется, и нажмите «Слить».

Товары перейдут на оставшееся значение, а старый адрес приведёт на новый. Отменить это нельзя.

## Как сделать фильтр числа готовыми шагами

1. Включите «В фильтре», в поле «Фильтр» выберите «Интервалы» и сохраните.
2. Откройте вкладку «Интервалы» и нажмите «Добавить интервал».
3. Заполните подпись и границы каждого шага.
4. Нажмите «Сохранить интервалы».

## Как открыть страницы одного значения поисковикам

1. Включите «В фильтре» и «Страницы одного значения открыты поисковикам».
2. Заполните «Шаблон заголовка страницы» или оставьте шаблон каталога.
3. Нажмите «Сохранить».

Такая страница живёт внутри категории: например, чёрные ноутбуки.

# fields

## title

Это слово покупатель видит в характеристиках, на плитке и над фильтром. Называйте так, как говорят
покупатели: «Размер экрана», а не «Парам. дисплея 2».

## code

Писать можно как угодно, на каждом языке: поле сразу превращает набранное в код и читает его по
правилам этого языка — «Тормозные колодки» станет `tormoznye-kolodki`.

Если поменять, изменятся адреса страниц фильтра с этим свойством, а поисковикам нужно время, чтобы это
заметить. Покупатель видит код только в адресе.

## type

Самый долговечный выбор в этой форме. Справочник даёт покупателю список на выбор, число может стать
слайдером, текст только читается, а да / нет — это один переключатель в фильтре.

## group-id

Задаёт заголовок, под которым свойство стоит в характеристиках на странице товара. Без группы оно идёт
последним, без заголовка.

## is-multiple

Включайте, когда у товара их действительно может быть несколько: набор цветов, список подходящих моделей.
Если выключено, у товара ровно одно значение и форма предлагает один выбор.

## is-tree

Для вложенных значений: страна и город, марка и модель. Покупатель открывает фильтр по уровням, а вы
перетаскиваете значения друг в друга на вкладке «Значения».

## leaves-only

Если включено, товар может получить только значение, под которым ничего нет: город, а не страну. Так
фильтр остаётся точным.

## value-order

«По алфавиту» работает на каждом языке само и не требует заботы. «Вручную» выбирайте для значений с
естественным порядком, например S, M, L, XL: их вы перетаскиваете на вкладке «Значения».

## has-color

У каждого значения появится цвет, и фильтр нарисует его перед названием. Полезно для свойства вроде
«Цвет», где покупатель смотрит, а не читает.

## has-image

У каждого значения появится маленькая картинка, и фильтр нарисует её перед названием. Полезно для
материалов и узоров, которые трудно описать словами.

## unit-prefix

Печатается на сайте прямо перед числом: например, знак валюты или «от». Большинству свойств не нужно.

## unit-suffix

Печатается на сайте сразу после числа: «кг», «см», «Вт». Пример под полями показывает, что прочитает
покупатель.

## precision

Решает, как округляется число на сайте. При весе 1,25 кг с двумя знаками число останется как есть, а с
нулём знаков покажется 1.

## toggle-slug

Писать можно как угодно: «Есть в наличии» станет `est-v-nalichii`, каждый язык читается по-своему.

Покупатель видит это слово только в адресе страницы фильтра. Если поменять, изменятся и эти адреса, так
что, когда фильтр уже работает, лучше не трогать.

## is-filterable

Покупатель сможет сузить каталог по этому свойству в категориях, где оно есть. Фильтр по тому, что никто
не выбирает, только удлиняет колонку: оставьте его для того, что действительно помогает выбрать.

## filter-mode

Слайдер подходит для плавного диапазона, например веса. Интервалы — это готовые шаги: покупатель
нажимает «1–2 кг», а не двигает слайдер. Шаги задаются на вкладке «Интервалы».

## is-indexable

Позволяет странице вроде «чёрные ноутбуки» появиться в поиске. Открывайте только значения, которые люди
действительно ищут: сотни почти пустых страниц вредят сайту.

## seo-pattern

Заголовок страницы одного значения в поиске и на вкладке браузера. Ставьте слова в том порядке, в каком
их написал бы человек в поиске.

## is-searchable

Поиск по сайту найдёт товары и по значению этого свойства: кто введёт «графит», получит товары этого
цвета. Включайте для слов, которые покупатели действительно вводят.

## in-card

Значение печатается на плитке товара в каталоге. Места на плитке мало, поэтому оставьте это для одного-двух
свойств, по которым выбирают.

## on-page

Значение печатается в характеристиках на странице товара. Здесь должно быть большинство свойств;
выключайте только у служебных значений, которые покупателю не нужны.

## in-list

Добавляет колонку в список товаров в панели, для вашей работы. Покупатель этого не видит.
