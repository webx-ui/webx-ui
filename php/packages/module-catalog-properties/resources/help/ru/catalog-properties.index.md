# about

Свойства описывают товар: цвет, вес, размер экрана. Из них складываются характеристики на странице
товара и, если нужно, фильтр каталога. Здесь вы создаёте свойства и задаёте их порядок, а категория
решает, какие из них есть у её товаров.

# howto

## Как добавить свойство и показать его в фильтре

1. Нажмите «Новое свойство», заполните название и выберите тип. Потом тип не поменять.
2. Включите «В фильтре» и нажмите «Сохранить».
3. Откройте категорию и добавьте свойство на её вкладке «Свойства».
4. Заполните значение в карточках товаров на вкладке «Характеристики».

## Как поменять порядок в фильтре

1. Сбросьте отборы над списком, если они заданы.
2. Перетащите свойства в списке.

Категория со своим порядком на вкладке «Фильтры» сохранит его.

## Как вернуть удалённое свойство

1. Откройте «Удалённые».
2. Найдите свойство и нажмите «Восстановить».

Значения у товаров сохранялись, поэтому фильтр и старые адреса вернутся вместе с ним.
