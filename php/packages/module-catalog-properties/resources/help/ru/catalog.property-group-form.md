# about

Группа — это заголовок в характеристиках на странице товара: «Экран», «Процессор». Здесь вы называете
её и решаете, видит ли покупатель заголовок. Свойства попадают в группу в своих формах.

# fields

## title

Покупатель читает это над свойствами группы. Хватит одного-двух слов: «Экран», «Размеры».

## is-visible

Выключайте, когда свойства должны стоять вместе на своём месте, но отдельный заголовок им не нужен:
например, в коротком блоке из двух-трёх строк.
