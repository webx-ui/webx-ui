# howto

## Как выбрать, какие свойства есть у категории

1. Сохраните категорию, если она новая.
2. Откройте вкладку «Свойства».
3. Нажмите «Добавить свойство…» и выберите одно, затем следующее.

Товары этой категории и всего, что под ней, получат эти свойства в своих карточках. Свойства категорий
выше приходят сами. Покупатель сможет выбрать свойство в фильтре, если в форме свойства включено
«В фильтре». Если в форме категории есть вкладка «Фильтры», на ней можно сократить этот список для
категории.
