# about

Група — це заголовок у характеристиках на сторінці товару: «Екран», «Процесор». Тут ви називаєте її й
вирішуєте, чи бачить покупець заголовок. Властивості потрапляють у групу у своїх формах.

# fields

## title

Покупець читає це над властивостями групи. Досить одного-двох слів: «Екран», «Розміри».

## is-visible

Вимикайте, коли властивості мають стояти разом на своєму місці, але окремий заголовок їм не потрібен:
наприклад, у короткому блоці з двох-трьох рядків.
