# howto

## Як вибрати, які властивості є в категорії

1. Збережіть категорію, якщо вона нова.
2. Відкрийте вкладку «Властивості».
3. Натисніть «Додати властивість…» і виберіть одну, потім наступну.

Товари цієї категорії й усього, що під нею, отримають ці властивості у своїх картках. Властивості категорій
вище приходять самі. Покупець зможе вибрати властивість у фільтрі, якщо у формі властивості ввімкнено
«У фільтрі». Якщо у формі категорії є вкладка «Фільтри», на ній можна скоротити цей список для
категорії.
