# about

Загружает в каталог файл CSV или XLSX за три шага: файл, его колонки и то, как записывать. Каждая
строка сохраняется как форма товара, с теми же проверками. Сначала запустите проверку: она покажет
все ошибки и ничего не запишет.

# howto

## Как провести импорт безопасно

1. На шаге «Файл» загрузите файл или укажите его адрес и нажмите «Прочитать файл».
2. На шаге «Колонки» укажите, в какую колонку каталога идёт каждая колонка файла. Для ненужных
   выберите «Не загружать».
3. На шаге «Настройки» выберите, как искать товары и какие строки брать.
4. Введите название в «Сохранить как профиль» и нажмите «Сохранить», чтобы не повторять всё это.
5. Нажмите «Проверить без записи». Проверка откроется в «Обмене»: прочитайте её ошибки.
6. Снова нажмите «Импорт», выберите профиль, укажите файл и нажмите «Запустить импорт».

## Как обновить только цены

1. На шаге «Колонки» оставьте ключевую колонку и цену, для остальных выберите «Не загружать».
2. В «Строках файла» выберите «Только обновлять найденные товары».
3. Оставьте выключенным «Пустая ячейка стирает поле», чтобы пропуск в файле не стёр цену.

## Как снять с сайта то, чего поставщик больше не продаёт

1. В «Товарах, которых нет в файле» выберите «Снять с сайта».
2. В «Среди» выберите «Товаров категорий, которые есть в файле», если в файле не весь ваш каталог.
3. Сначала запустите проверку и посмотрите, сколько товаров она снимет.

## Как загружать один и тот же файл в один шаг

1. На последнем шаге введите название в «Сохранить как профиль» и нажмите «Сохранить».
2. В следующий раз выберите этот профиль на первом шаге или нажмите «Импорт с ним» в «Профилях».

# fields

## key

Выбирайте то, что не расходится между файлом и каталогом. Если искать по артикулу, товар с вручную
изменённым номером покажется импорту новым. Покупатель этого выбора не видит.

## mode

Безопаснее всего загружать прайс с вариантом «Только обновлять найденные товары»: незнакомая строка
не создаст на сайте полупустой товар по случайности.

## empty_clears

Осторожно: когда включено, пустая ячейка стирает это поле у товара, включая цену. Включайте, только
если пустые ячейки в файле действительно значат «здесь больше ничего нет».

## create_missing

Удобно для первого большого импорта. Для регулярных обновлений оставьте выключенным: иначе опечатка в
названии категории создаст на сайте новую категорию вместо ошибки, которую вы увидите.

## absent

«Снять с сайта» может спрятать большую часть каталога, если файл неполный, поэтому сначала проверьте
файл. Снятые товары можно опубликовать снова. Если прогон остановится раньше, ничего снято не будет.

## absent_scope

«Всего каталога» снимает с сайта всё, чего нет в файле, поэтому выбирайте это только для файла со всем
ассортиментом. Для прайса одного поставщика оставайтесь в категориях файла.

## images

Важно, только если в файле есть колонка с адресами картинок. «Заменять галерею» снимает картинки,
которых нет в ячейке, и покупатель их больше не увидит. Картинки скачиваются после записи строк,
поэтому могут появиться чуть позже.
