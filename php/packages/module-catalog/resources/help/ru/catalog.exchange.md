# about

Товары входят в каталог и выходят из него файлами-таблицами: прайс поставщика внутрь, список для
бухгалтера наружу. Каждый импорт, проверка и экспорт остаются в этом списке вместе с тем, что они
сделали, так что всегда видно, кто что менял. Откройте строку, чтобы увидеть итоги, ошибки и файл.

# howto

## Как обновить цены из файла

1. Нажмите «Импорт» и укажите файл.
2. Сопоставьте его колонки с колонками каталога и нажмите «Дальше».
3. Выберите, как искать товары: например, по артикулу.
4. Нажмите «Проверить без записи». Проверка появится в этом списке: прочитайте её ошибки.
5. При необходимости исправьте файл, снова пройдите «Импорт» и нажмите «Запустить импорт».

## Как выгрузить товары

1. Нажмите «Экспорт».
2. Выберите профиль или отметьте нужные колонки.
3. Нажмите «Выгрузить». Файл появится в этом списке, когда будет готов.

Чтобы выгрузить только часть товаров, отметьте их в «Товарах» и выберите экспорт в «Действиях».

## Как прочитать итог прогона

1. Откройте строку прогона.
2. Посмотрите итоги: создано, обновлено, пропущено и ошибки.
3. Нажмите «Скачать все ошибки CSV», чтобы увидеть каждую отклонённую строку с причиной.
4. Откройте «Изменения в журнале», чтобы увидеть, что импорт поменял по каждому товару.

Плохая строка не мешает остальным: они записываются. Только статус «Остановлен» значит, что ошибок
оказалось слишком много и прогон прервался. Записанное до остановки остаётся.

## Почему не скачивается файл прогона

Файлы хранятся ограниченное время, потом удаляются, и строка об этом скажет. Файл прогона доступен
тому, кто его запустил, и суперадминистраторам. Строка с итогами хранится намного дольше.
