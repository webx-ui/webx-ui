# about

Завантажує до каталогу файл CSV або XLSX за три кроки: файл, його колонки й те, як записувати. Кожен
рядок зберігається як форма товару, з тими самими перевірками. Спершу запустіть перевірку: вона
покаже всі помилки й нічого не запише.

# howto

## Як провести імпорт безпечно

1. На кроці «Файл» завантажте файл або вкажіть його адресу й натисніть «Прочитати файл».
2. На кроці «Колонки» вкажіть, у яку колонку каталогу йде кожна колонка файлу. Для непотрібних
   виберіть «Не імпортувати».
3. На кроці «Налаштування» виберіть, як шукати товари й які рядки брати.
4. Введіть назву в «Зберегти як профіль» і натисніть «Зберегти», щоб не повторювати все це.
5. Натисніть «Перевірити без запису». Перевірка відкриється в «Обміні»: прочитайте її помилки.
6. Знову натисніть «Імпорт», виберіть профіль, вкажіть файл і натисніть «Запустити імпорт».

## Як оновити лише ціни

1. На кроці «Колонки» залиште ключову колонку й ціну, для решти виберіть «Не імпортувати».
2. У «Рядках файлу» виберіть «Лише оновлювати знайдені товари».
3. Залиште вимкненим «Порожня клітинка стирає поле», щоб пропуск у файлі не стер ціну.

## Як зняти із сайту те, чого постачальник більше не продає

1. У «Товарах, яких немає у файлі» виберіть «Зняти із сайту».
2. У «Серед» виберіть «Товарів категорій, які є у файлі», якщо у файлі не весь ваш каталог.
3. Спершу запустіть перевірку й подивіться, скільки товарів вона зніме.

## Як завантажувати той самий файл за один крок

1. На останньому кроці введіть назву в «Зберегти як профіль» і натисніть «Зберегти».
2. Наступного разу виберіть цей профіль на першому кроці або натисніть «Імпорт із ним» у «Профілях».

# fields

## key

Вибирайте те, що не розходиться між файлом і каталогом. Якщо шукати за артикулом, товар із вручну
зміненим номером здаватиметься імпорту новим. Покупець цього вибору не бачить.

## mode

Найбезпечніше завантажувати прайс із варіантом «Лише оновлювати знайдені товари»: незнайомий рядок
не створить на сайті напівпорожній товар випадково.

## empty_clears

Обережно: коли ввімкнено, порожня клітинка стирає це поле в товару, зокрема ціну. Вмикайте, лише якщо
порожні клітинки у файлі справді означають «тут більше нічого немає».

## create_missing

Зручно для першого великого імпорту. Для регулярних оновлень залиште вимкненим: інакше помилка в
назві категорії створить на сайті нову категорію замість помилки, яку ви побачите.

## absent

«Зняти із сайту» може сховати більшу частину каталогу, якщо файл неповний, тож спершу перевірте файл.
Зняті товари можна опублікувати знову. Якщо прогін зупиниться раніше, нічого знято не буде.

## absent_scope

«Усього каталогу» знімає із сайту все, чого немає у файлі, тож вибирайте це лише для файлу з усім
асортиментом. Для прайсу одного постачальника залишайтеся в категоріях файлу.

## images

Важливо, лише якщо у файлі є колонка з адресами зображень. «Замінювати галерею» знімає зображення,
яких немає в клітинці, і покупець їх більше не побачить. Зображення завантажуються після запису
рядків, тож можуть з'явитися трохи пізніше.
