# about

A profile remembers the columns and settings of an import or an export, so a file you bring in every
week takes one step instead of three. Keep one profile for each supplier or each regular report.

# howto

## How to make a profile

1. Press «New import profile» or «New export profile».
2. Give it a name, choose the format and fill in its columns.
3. Press «Save».

An easier way: on the last step of an import, type a name in «Save as profile» and press «Save».

## How to import with a profile

1. In the row of the profile, press «···» and choose «Import with it».
2. Give the file. Its columns are matched by the profile.
3. Check the file and run the import.

A profile that has never run asks for a check first.

## How to delete a profile

1. In the row of the profile, press «···» and choose «Delete».

The runs made with it stay in «Exchange».
