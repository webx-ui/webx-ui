# about

Products go in and out of the catalogue as spreadsheet files: a supplier's price list in, a list for
your accountant out. Every import, check and export stays in this list with what it did, so you can
always see who changed what. Open a row for its totals, errors and file.

# howto

## How to update prices from a file

1. Press «Import» and give the file.
2. Match its columns to the columns of the catalogue, and press «Next».
3. Choose how to find products: by article number, for example.
4. Press «Check without writing». The check appears in this list: read its errors.
5. Fix the file if you need to, go through «Import» again and press «Run the import».

## How to export products

1. Press «Export».
2. Choose a profile, or tick the columns you need.
3. Press «Export». The file appears in this list when it is ready.

To export only some products, tick them in «Products» and choose the export in «Actions».

## How to read the result of a run

1. Open the row of the run.
2. Look at the totals: created, updated, skipped and errors.
3. Press «Download all errors as CSV» to see every refused row with its reason.
4. Open «Changes in the journal» to see what the import changed, product by product.

A bad row does not stop the others: they are written anyway. Only «Stopped» means there were too many
errors and the run gave up. What was written before it stopped stays.

## Why the file of a run cannot be downloaded

Files are kept for a limited time, then removed, and the row says so. The file of a run is available
to whoever started it and to super administrators. The row with its totals stays much longer.
