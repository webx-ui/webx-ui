# about

Типы блоков, из которых собирается содержимое сайта. Тип заводится здесь целиком, с полями, шаблоном
и стилями, а редакторы потом заполняют его на страницах. Опубликованная правка доходит до всех
страниц, где стоит блок, поэтому этот раздел — для того, кто отвечает за вёрстку сайта.

# howto

## Как сделать новый блок

1. Нажмите «Новый блок» и выберите «Вид»: «Блок» для страниц, «Компонент» для вызова из других
   шаблонов.
2. Заполните «Название», «Идентификатор» и «Группа» и нажмите «Создать».
3. В редакторе напишите шаблон, стили и поля и заполните образец.
4. Нажмите «Опубликовать». Только теперь редакторы смогут его добавить.

## Как поменять порядок в списке блоков

1. Откройте вкладку группы или «Все группы» и очистите поиск.
2. Перетащите карточки в нужном порядке.
3. Откройте «Добавить блок» на странице и проверьте: редакторы видят тот же порядок.

Порядок сохраняется сам и не влияет на стили блоков на сайте.

## Как перенести блоки на другой сайт

1. Нажмите «Экспорт», отметьте типы и нажмите «Скачать». Компоненты, которые они вызывают, поедут
   вместе с ними.
2. На другом сайте нажмите «Импорт» и «Выбрать файл».
3. Прочитайте, что будет с каждым типом: новый, отличается, без изменений или отклонён.
4. Нажмите «Импортировать». Новые типы приходят черновиками.

Тип, который на другом сайте уже есть, остаётся как был. Чтобы взять версию из файла, включите
«Заменить» в его строке.

## Как настроить стандартный вид раздела

1. Откройте «Компоненты» и найдите карточку с кнопкой «Настроить».
2. Нажмите «Настроить»: из стандартного вида получится черновик.
3. Измените его и нажмите «Опубликовать». До этого сайт показывает стандартный вид.

Чтобы вернуться, нажмите «Сбросить к стандартному» в редакторе этого компонента: его версии
удалятся, и стандартный вид вернётся.

# fields

## Скрыт от редакторов

Тип больше нельзя добавить, но страницы, где он стоит, продолжают его показывать. Переключатель —
«Предлагается редакторам» на вкладке «Настройки» типа.

## Не опубликован

Тип ни разу не публиковали: редакторы не смогут его добавить, а сайт его не покажет. На карточке
опубликованного типа видны версия на сайте и ждущий черновик.
