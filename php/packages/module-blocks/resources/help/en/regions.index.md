# about

The parts of the site that stand on many pages: the header, the footer and shared blocks. Each one
is built of blocks and published like a page, and one change reaches every page it stands on. While
a region has nothing published, the site shows what its code draws there.

# howto

## How to change the header or the footer

1. Open the card of the region.
2. Add or change blocks and check them in the preview.
3. Press «Publish»: every page of the site shows the new version at once.

## How to bring back the header from the code

1. Open the card of the region.
2. Press «Take off the site» and confirm.

Nothing has to be deleted: the blocks stay as a draft, and «Publish» brings them back.

## How to change a shared block

1. Find it under «Shared blocks» and open its card.
2. Check how many pages it stands on: the card says so.
3. Change it and press «Publish».

Every page that holds it changes. Where it is shown is decided by the pages, not here: to take it
off one page, remove it from that page.

# fields

## Fallback from code

Nothing published: visitors see what the code of the site draws in this place. The card names that
markup, or says there is none. To replace it, open the region, add blocks and publish.

## On the site

Visitors see the published blocks. «Edits waiting» beside it means a draft is not published yet, and
visitors do not see it.

## Draft

Blocks are saved but were never published, so the site still shows the fallback from code.
