# about

The blocks of one region: the header, the footer or a shared block. Changes are saved into a draft,
and a preview shows them on a real page of the site. Publishing changes every page the region stands
on at once.

# howto

## How to check a region on another page

1. In «Shown on» at the top, pick a page of the site or type its address.
2. Look at the region on that page: the page itself is shown as published.
3. Press «Open the preview» for a full view in a new tab.

For a shared block, «Where it stands» lists the pages that hold it, and each of them can be opened
in the preview.

## How to publish a region

1. Change the blocks. The draft is saved by itself, and «Save draft» does it right now.
2. Press «Publish» and confirm.

If a block fails to draw, publishing is refused and names the block, so a broken header does not
reach the site.

## How to turn the header from the code into blocks

1. Open an empty region: the notice says what the site shows there now.
2. Press «Move the markup into a block». The button needs the right to edit block types.
3. Check the new block in the preview: the markup is now in the draft as one block.
4. Press «Publish».

The block holds the markup as it was, without separate fields: its text is changed in the block
type, in the «Blocks» section.

## How to go back

1. To drop a draft, press «Discard draft»: the region becomes what the site shows.
2. To return an old publication, press «Restore» on the «History» tab, then «Publish».
3. To return to the markup from the code, press «Take off the site».

A discarded draft cannot be brought back. Restoring leaves the site as it is until you publish.

# fields

## blocks

Everything visitors see in this place of every page is these blocks, and which types are allowed
here is set for each region. If any block fails on the site, the whole region falls back to the
markup from the code, so that the visitor does not lose the navigation.
