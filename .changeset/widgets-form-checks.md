Checks in the browser (WIDGETS §17.5, W6.3). `webx-ui/widgets`: **`WebxUi\Widgets\Forms\FormRules::for($rules, $attributes, $messages)`** on `<x-webx-form :rules>` (or `:rules` on one field) hands each `<x-webx-field>` its part of the server's rules — `required`, `accepted`, `email`, `url`, `numeric`, `integer`, `min`/`max`/`between`/`size` by the field, `regex`/`not_regex` that mean the same in JavaScript, `in`, `mimes`, `extensions`, `mimetypes`, `image`, `confirmed`, `same`, `different`, `date`, `after`/`before` with a literal date, with `bail` and `nullable` — as `data-webx-rules`, each check with the very line Laravel's validator writes, asked of the validator in the page's language; plus `required`, a number's or a date's `min`/`max`, a file's `accept`. Everything else stays the server's, silently. `dist/form.js` (≈4.6 KB gzip with the shell) checks a touched field when it is left and every field on submit, sends nothing while one is wrong, turns the browser's bubbles off; `formnovalidate` goes straight to the server. **Phone mask** — `<x-webx-field type="tel" mask>` (`dist/mask.js`): `+` country code and groups of digits, paste and autofill untouched. **Files** — every file field (`dist/files.js|css`): drop, a list with sizes and previews, Remove before sending, a refused file marked on its row; words `widgets.field.remove|drop_file|drop_files` in ten languages. `POST webx/widgets/showcase/validation` answers while the demo is on the site. `webx-ui/theme-default`: Kitchen sink › Forms › Validation (en/ru/pl) — one form checked in the browser and by the server in the same words, the mask, the files.
