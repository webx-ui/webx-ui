`webx-ui/module-catalog-collections`: the offered block `product-collection` puts a collection on any page or region, with its own heading, view and a limit that can only lower the collection's. Install it with `php artisan webx:blocks:offered --install`. The field `wx-catalog-collection` keeps the key and refuses an unknown one only when it is written, naming the keys there are; the relation target `catalog-collection` lists the collections for the picker.
