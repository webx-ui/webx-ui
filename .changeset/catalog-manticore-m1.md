New package `webx-ui/module-catalog-manticore`: Manticore as the catalogue engine — a table per language with the morphology of every language of the site, facets and counts in one round trip, rebuilds swapped in whole, the database or a 503 to fall back on, and doctor checks. The core gains `RebuildsAside`, `FacetPlacement`, `IndexField::JSON` and the index side of `BatchCountedFacet`; the properties write `pn` as a JSON map.
