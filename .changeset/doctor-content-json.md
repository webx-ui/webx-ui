`webx:doctor` tells notes on the content apart from warnings about the setup. `Diagnosis::content()` is a warning marked `(content)` — mended in the panel, so `--strict` no longer stops a deploy on it, and the closing line counts it apart. Moved to it: a shared block no page places (`module-blocks`), a property code that clashes with a column of the exchange and pages hidden under the catalogue's root (`module-catalog`). `--json` prints `{checks: [{state, subject, detail, content}], failed, warned, content}`, with `warned` counting only the warnings `--strict` stops on.
