The public side of a site asks the database far less (webx-ui#16, stage 3). `routing`: `url()` and `routeCanonical()` answer from the loaded `routes` relation, so a list loaded `with('routes')` prints its addresses without a query per card; the resolver keeps the addresses it found in the `routes` cache group; `Untranslated` reads the loaded rows too. `module-seo`: the SEO card is read once per entity, the breadcrumb trail is built once per request, `hreflang` comes from the loaded rows, the sitemap is cached on the `sitemap` group and asks each model for `scopeForSitemap()` (covers, addresses, `lastmod` for a chunk at once). `cache`: `remember()`/`get()`/`put()` keep what they read for the request, and `prefetch(name, depends, localized)` declares an entry every page reads — the settings, the languages, the block types, the regions, the SEO rules — so the first read of a request brings them all with the versions in one `many()`. `module-admin`: the field-type marker `PreloadsValues`; `module-blocks` walks the tree before rendering (nested lists and repeater items included) and hands every such type its values at once, `module-media` loads the pictures and galleries of a page in one query (`MediaFiles::load()` notes the keys, the first `find()` looks them all up). Settings, locales, menus (one version for all menus, with `routes`), block types, regions, bundles, SEO rules, link blocks, snippets and the sitemap live on versioned keys; the `onReset` bridges of what moved are gone. Blog and pages: `with('routes')` on feeds, related and ancestors, `scopeForSitemap()` on `Article` and `Page`; every public page of each module has a query budget test (`tests/PerformanceTest.php`, cold and warm) and a freshness test through the panel. New indexes: `routes (entity_type, locale, kind)`, `media_files path(255)` (a prefix on MySQL/MariaDB) and `(directory_id, created_at)`, `audit_issues (page_id, ignored_by)`, `audit_links (to_page_id)`, `(host, run_id)`, `cms_history (event, subject_type)`, `(event, created_at)`, `blog_articles (deleted_at, pinned, published_at)`. On a MariaDB site with the `database` cache store a typical page went from 33 queries to 18, a page of picture cards from 44 to 19, and a cold `/sitemap.xml` from 133 to 18; HTML unchanged.
