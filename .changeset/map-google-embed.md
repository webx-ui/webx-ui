A map from Google Maps' "Embed a map", with no API key. `<x-webx-map embed="…">` takes Google's whole `<iframe …>` or its address, keeps only `https://www.google.com/maps/embed?pb=…` (and the older `maps.google.com/maps?…&output=embed`) and refuses any other frame; it is the same frame, notice, "Load" / "Always load maps" and consent to `media` as every map, and the script (`dist/map-embed.js`, no library) puts Google's `<iframe>` in — with its `title`, `loading="lazy"` and `referrerpolicy="no-referrer-when-downgrade"` — only after consent, in the height the server reserved. "Open in Google Maps" is `link`, else read from the address (the centre of a `pb`, the search of an old one). Every map takes `height-narrow`, its height in a column narrower than 36em. The `map` block gets the place "Google Maps embed" with the fields "Map code or link" and "Link “Open in Google Maps”", and for every place "Name for screen readers", "Height on a phone" and "Width" (column / edge to edge); blocks saved before print as they did. The panel gets the field type `wx-embed`: a frame pasted as code, kept by the server as its address alone, refused with the source's words when it is another site's — whoever writes it, the panel or an agent's `blocks_*`; sources are registered into `Screens\Embeds`, `google-maps` by the widgets.
