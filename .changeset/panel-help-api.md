Справка панели: `GET /api/cms/help/{key}` отдаёт справку экрана на языке панели — текст из файлов, подписи, подсказки и вкладки из дерева экрана, с теми же правами, что у формы. В манифесте появился список ключей `help`. Новая настройка `webx-admin.docs_url` (`WEBX_ADMIN_DOCS_URL`, по умолчанию пусто) включает ссылку на гайд.
