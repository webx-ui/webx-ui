Fonts of the theme (THEMES §15.3, TH4.5). `webx-ui/themes`: **`fonts` in the manifest** is a list of faces — `family`, `weight` (`"400"`, or `"100 900"` for a variable font), `style` and `files`, a map of script to a file under the layer's `assets/` (`latin`, `latin-ext`, `cyrillic`, `cyrillic-ext`, `greek`, `greek-ext`, `vietnamese`). **`@webxTheme` prints an `@font-face` per file with its script's `unicode-range`**, so a page downloads only the scripts its letters need — an English page never the Cyrillic file; a family of a higher layer replaces the same family below. **`webx:theme:check`** names an entry it cannot read (an unknown script, a URL instead of a file, a missing file, not a web font) and a script the site's languages or the layer's own `locales` need and no file covers — `ru`/`uk` need `cyrillic`, `pl`/`tr` `latin-ext`; `--locales=` compares other languages. **`webx:doctor`** warns the same where `module-admin` is installed. `webx-ui/theme-default`: **Inter as its own files** — variable, 100–900, upright and italic, in Latin, Latin Extended and Cyrillic, with the SIL Open Font License beside them; `font-body` starts with `Inter`. Its showcase gets «Kitchen sink › Fonts». `webx-ui/widgets`: the language switcher sets the names of the other languages in the reader's font (`is-other`), so «Русский» costs an English page no Cyrillic download.
