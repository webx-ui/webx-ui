The satellites of the catalogue are columns of exchange files (E2 of the exchange series). `labels` — label codes through `;`; `stock` — the code of a stock status, never created by an import; `brand` — a slug, else the name without regard to case, or `#id`; and a column for every property, named by its code in the default language (`-` written `_`, `code@de` for a translated text): a reference book by name, `;` between several and `/` down a tree, a number without its unit, yes or no as `is_published` reads it, a text as it is. With `create_missing` an import creates labels, brands and values of properties, a tree of them by path, and only for whoever may manage the catalogue; the export writes what the import reads back, so a file with every part sent back untouched changes nothing. New in the core: `EntryColumn` (several columns making one object field of the form), `Lookup` (a reference book cached for the run) and a `webx:doctor` warning for a property whose code is a column of the core and is `p_<code>` in files. `null` for a property outside the set of the product's category is no longer refused by the form: there is nothing of it to take away.
