`webx-ui/widgets`: the page tools (spec §14, W5.1). **Tables of prose** — every `<table>` without a class on a page (what a rich text field stores, whichever module prints it) is put by the server in a frame that scrolls sideways, its `<caption>` taken out above the frame so that it does not scroll away and still names the table and the frame (`aria-labelledby`; "Table" without one); `dist/table.js|css` draws a shadow on the side there is more behind and takes the tab stop off a table that fits. A table a template wrote has a class and is left as it is. **`data-webx-reveal`** in the runtime — `up`, `fade`, `scale`, or `stagger` on a container with `data-webx-reveal-effect` for its children: an element comes in once as it scrolls into view; only the script hides anything, and only what is below the screen when the page opens — without JavaScript or with reduced motion everything is there. **`<x-webx-back-to-top corner :after>`** — a round button in a corner after two screens, smooth unless reduced motion, the focus left at the top, above the cookie banner, the contact bar and the quick contact of its corner; without JavaScript a link to `#top`. **`<x-webx-share title url :networks>`** — each network's own address for sharing as a plain link (Facebook, X, LinkedIn, Telegram, WhatsApp, e-mail and Copy link by default; Viber, Reddit, Pinterest, Threads, Bluesky, VK on request), no network's script; on a phone one Share button opens the system's share sheet. Words in ten languages, icons `arrow-up` and `share`. `webx-ui/theme-default`: Kitchen sink › Page tools.
