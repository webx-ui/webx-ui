The exchange to an agent: `catalog_exchange_columns`, `catalog_import` (a file by address, the
panel's suggested mapping when none is given, `dry_run` as the import's own check),
`catalog_export`, `catalog_exchange_run` and `catalog_exchange_profiles`, and the resource
`catalog://exchange` with how every cell of the core and the satellites reads (`DescribesCell`).
The signed link of an export ends with the file's name, so an import by it knows the format; a
category an import creates under a name the tree already has elsewhere gets a numbered slug instead
of failing every row of its branch.
