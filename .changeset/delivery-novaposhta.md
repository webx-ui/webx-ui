New package `webx-ui/delivery-novaposhta`: Nova Poshta for delivery. The carrier `novaposhta` (Ukraine) with its API key, the settings of payment, cargo type, weight and description, «Test the connection» that reads the account's senders, and its mark from the package. Three method types — branch, parcel locker, courier — priced «by the carrier's rates» without asking the API; the migration adds three methods switched off. `Api\Client` is a thin client of the carrier's JSON API: the answer read by `success`, a 303 to a cached file followed, failures in the base's words, the key never in a log or an exception. It lists every reading and writing method, refuses a writing one before any request with `NOVAPOSHTA_READ_ONLY=true`, and keeps a journal of calls (model, method, outcome — no key, no data). Words in 10 languages. Numbers of a request go as strings, as the carrier wants them. `php artisan webx:novaposhta:record` records a scrubbed answer of a reading method for the tests (development copies only, read-only mode only, the key from `NOVAPOSHTA_KEY`).
