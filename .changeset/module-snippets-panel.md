New package `@webx-ui/module-snippets`, the panel's «Codes» section: every place of `config/webx-snippets.php` with its codes, dragged into order inside a place or into another place, switched on and off from the row; the form `snippets.form` with the code in a highlighting editor and the server's warnings above it; the bin. The list says when the site is not in production, which declared place no page has printed yet (`last_seen`, new in the panel API of `webx-ui/module-snippets`) and which place nobody declares any more. `webx:module:add snippets` now knows the module.
